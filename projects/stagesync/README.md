# StageSync media

Add real project files to the folders below, then update only the paths in
`components/stagesync/stagesync-data.ts`.

- `cover/`: landscape hero cover
- `process/wickham-theatre.jpg`: 剧院场地调研
- `process/team-members.png`: 跨端系统设计与开发
- `process/user-testing.png`: 原型测试与迭代
- `diagram/`: asymmetric collaboration system diagram
- `videos/`: feature demonstration videos
- `posters/`: video poster images

Null media paths intentionally render the designed placeholders. No media from
another project is used as a substitute.
