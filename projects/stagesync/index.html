OVERVIEW

StageSync 是一套面向舞台灯光预演的跨设备协作系统。项目以布里斯托大学 Wickham Theatre 为原型，将运行于 Meta Quest 的沉浸式 VR 预览端与面向平板浏览器的 Web 控制端结合。VR 用户可以在虚拟剧院中从舞台或观众席的不同位置评估灯光和空间效果，Web 用户则负责灯光参数调节、Cue 管理、视点控制和协作状态查看。项目通过两端能力互补的非对称交互，探索正式进场和技术排演前更加直观的灯光方案讨论与协作方式。

StageSync is a cross-device collaborative system for stage-lighting previsualisation. Based on the University of Bristol’s Wickham Theatre, it combines an immersive VR preview running on Meta Quest with a browser-based control interface designed primarily for tablets. The VR user can evaluate lighting and spatial effects from different positions in the virtual theatre, while the Web user manages lighting parameters, cues, viewpoints and shared system states. Through complementary asymmetric interaction, the project explores a more intuitive way to discuss and evaluate lighting ideas before entering the physical theatre and beginning technical rehearsals.

Key Features

01

Lighting Control

Web 端可以选择剧院灯具，并根据灯具类型调节 Pan、Tilt、Field Angle、亮度和颜色等参数。参数变化会同步至 VR 预览端，帮助协作者从不同位置观察光束方向、覆盖范围、明暗变化及舞台色彩效果。Colour 仅适用于支持颜色控制的 LED 灯具。

Teleportation

Web 用户可以通过剧院地图选择预设观察位置，并向 VR 用户发送传送请求。VR 用户确认后才执行移动，避免由外部用户强制改变其位置而造成不适。VR 用户也可以在舞台和观众席的预设视点之间移动，从不同空间位置观察灯光、舞台和观众视角下的整体效果。
